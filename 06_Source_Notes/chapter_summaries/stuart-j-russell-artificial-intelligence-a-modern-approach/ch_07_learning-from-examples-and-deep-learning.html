Part V, Chs. 19-22: Supervised, Probabilistic, and Deep Learning

Ch. 19 — Learning from Examples

Formal supervised-learning setup

Given training examples {(xi​,yi​)}i=1n​ drawn i.i.d. from an unknown distribution D, learn a hypothesis h∈H from a hypothesis space, minimizing expected loss

L(h)=E(x,y)∼D​[L(h(x),y)].

In practice we minimize empirical risk: L^(h)=(1/n)∑L(h(xi​),yi​).

Decision trees (ch. 19.3)

Greedy split-by-information-gain. Information gain of attribute A at node with examples E:

Gain(A)=H(E)−∑v​∣E∣∣Ev​∣​H(Ev​),

where H is Shannon entropy. Pruning controls overfitting (ch. 19.3.4).

PAC learning and VC dimension (ch. 19.5)

A hypothesis class H is PAC-learnable if there exists an algorithm that, with probability ≥1−δ, returns h with L(h)≤L(h∗)+ε from n=poly(1/ε,1/δ,VC(H)) samples.

VC dimension of H: the largest d such that H shatters some set of d points (can realize all 2d labellings). Russell gives the sample-complexity bound

n≥ε1​(logδ1​+VC(H)logε1​).

Linear regression and classification (ch. 19.6)

Linear regression: hw​(x)=w⊤x; minimize squared loss; closed-form w∗=(X⊤X)−1X⊤y. Logistic regression replaces output with sigmoid; loss minimized via gradient descent.

Nonparametric (ch. 19.7) and ensembles (ch. 19.8)

k-nearest-neighbours, kernel methods, decision-forest bagging, AdaBoost. Russell’s general claim: ensembling almost always helps; the bias-variance decomposition

E[L(h(x),y)]=Bias2+Var+Noise

explains why averaging high-variance learners reduces total error.

Ch. 20 — Knowledge in Learning

Inductive bias from prior logical / relational knowledge:

  • Explanation-based learning (EBL): use a domain theory to construct a proof of why a training example fits a target concept; generalize the proof.
  • Inductive logic programming (ILP): learn first-order Horn clauses from examples plus background theory (FOIL, Progol). The textbook is honest that ILP has been largely outpaced empirically by deep learning, but conceptually important for any neuro-symbolic agenda.

Ch. 21 — Learning Probabilistic Models

Maximum-likelihood estimation

For parameters θ and data D:

θ∗=argmaxθ​logP(D∣θ).

For Bayes nets with complete data, MLE decomposes per-CPT: θ^ijk​=Nijk​/Nij​ (frequency counts).

Bayesian learning

P(θ∣D)∝P(D∣θ)P(θ).

Conjugate priors (Beta-Binomial, Dirichlet-Multinomial) make updates closed-form.

Expectation-Maximization (ch. 21.3)

For models with latent variables Z:

  • E-step: compute Q(θ∣θ(t))=EZ∣D,θ(t)​[logP(D,Z∣θ)].
  • M-step: θ(t+1)=argmaxθ​Q(θ∣θ(t)).

EM monotonically increases the log-likelihood; canonical applications include Gaussian mixtures, HMM training (Baum-Welch), and PCA via probabilistic factor analysis.

Ch. 22 — Deep Learning

Feedforward networks (ch. 22.1)

A network of depth L computes

h(ℓ)=g(W(ℓ)h(ℓ−1)+b(ℓ)),h(0)=x,

with nonlinearity g (ReLU, sigmoid, tanh). Output layer + loss form a differentiable composition; gradients are computed by backpropagation (chain rule applied through the computation graph, ch. 22.2).

Convolutional networks (ch. 22.3)

Translation-equivariant architecture: a filter k slides over input; the convolution is (x∗k)[i]=∑j​x[i+j]k[j]. Parameter sharing reduces ∣W∣ from O(nin​nout​) to O(∣k∣) per channel pair.

Generalization (ch. 22.5)

Russell highlights the double-descent phenomenon — test error first decreases, then increases at the interpolation threshold, then decreases again as the model is heavily overparameterized — and the lottery-ticket hypothesis (Frankle & Carbin 2019). The textbook is careful to flag that generalization in deep nets is not yet theoretically settled.

Recurrent networks and transformers (ch. 22.6, ch. 25)

Recurrence: ht​=g(Wh​ht−1​+Wx​xt​). Suffer vanishing/exploding gradients; LSTMs and GRUs add gated paths.

Transformers (cross-referenced from ch. 25): the dot-product self-attention head is

Attn(Q,K,V)=softmax(dk​​QK⊤​)V.

Russell defers the full treatment to ch. 25.4, where it is presented as learned routing between tokens.
